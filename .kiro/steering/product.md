# 产品概述

## 乐美车辆预约系统

一个综合性的车辆预约和管理系统，由三个主要组件构成：

1. **后端 API (lemei)** - 基于 Java Spring Boot 的后端服务，提供系统管理的 REST API
2. **管理后台 (lemei-ui)** - 基于 Vue.js 的管理员控制台，用于系统管理
3. **小程序 (LMXCX)** - 基于 uni-app 的微信小程序，供终端用户进行车辆预约

## 核心功能

- 车辆预约和调度管理
- 用户和基于角色的访问控制
- 司机、承运商、仓库和门卫管理
- 实时监控和报表
- 多租户应用支持
- 定时任务调度管理
- 系统配置和字典管理
